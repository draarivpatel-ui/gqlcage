# Changelog

## 1.0.0 - 2026-11-27

Initial release.

- Iterative GraphQL executable-document lexer and parser.
- Memoized fragment DAG expansion analysis.
- Depth, expansion, alias, duplicate field, directive, argument, variable, input nesting, string length, operation, root field, token, and complexity policies.
- Introspection and operation type policy controls.
- SDL rejection in executable documents and byte order mark handling.
- HTTP JSON request and batch auditing with strict JSON data validation.
- Express-style middleware helper.
- ESM, CommonJS, TypeScript declarations, CLI, examples, and deterministic test suite.
