# Contributing

Contributions are welcome through issues and pull requests.

## Ground rules

- Keep the package at zero npm dependencies.
- Support Node.js 18, 20, 22, and 24.
- Keep lexer, parser, and analyzer recursion out of attacker-controlled nesting paths.
- Add regression tests for every security fix.
- Preserve both ESM and CommonJS behavior.
- Do not commit generated tarballs, `node_modules`, coverage output, secrets, or local machine paths.

## Verification

Run all checks before opening a pull request:

```sh
npm test
node scripts/build-cjs.mjs --check
node scripts/cli-smoke.mjs
npm pack --dry-run
```

`cjs/index.cjs` is generated by `scripts/build-cjs.mjs`. Edit `src/*.mjs`, then regenerate and commit the bundle.

Tests are ordinary `node:test` files under `tests/`. The runner enumerates files with `fs.readdirSync`, so new files must end in `.test.mjs`.

## Style

Use small explicit state machines for attacker-controlled nesting. Prefer typed `GqlCageError` failures with stable `GQLCAGE_*` codes. Keep public API changes backward compatible within a major version.
