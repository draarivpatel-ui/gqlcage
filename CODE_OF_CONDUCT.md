# Code of conduct

## Commitment

Participants in this project are expected to be respectful, factual, and constructive. Harassment, personal attacks, discriminatory language, sexualized conduct, doxxing, and sustained disruption are not acceptable.

## Scope

This code applies to project issues, pull requests, security reports, discussions, and other project spaces.

## Enforcement

Project maintainers may remove content, close participation, or report conduct to platform providers when needed to keep the project space safe.

Report conduct concerns through a private GitHub Security Advisory or another private maintainer channel when one is available. Do not post private information in a public issue.

## Standard

This project follows the spirit of the Contributor Covenant: use welcoming and inclusive language, respect differing viewpoints, accept constructive criticism, focus on what is best for the community, and show empathy toward other participants.
